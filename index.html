First time? Create an index

Run this once on your computer, then import my-library.json. Use a channel handle or a playlist URL.

uv run tools/index_source.py '@periodicvideos' --output my-library.json

YouTube prevents websites from reading its full listings directly. A saved index keeps Daily independent of a server or API key.

Channel indexes exclude Shorts. Playlist indexes keep the videos you put in the playlist, including Shorts.

Updating an existing source replaces its saved list and can change daily picks. Export its current library first if you want to keep it.

A SMALL DAILY RITUAL

Less choosing.
More discovering.

Daily turns a channel or playlist into one video for each day.

  1. Start with a library.Choose a ready collection in Browse suggestions, use Geography Now, or import your own.
  2. Let the date decide.We hash your device's local date with SHA-256 and pick a video from the sorted list.
  3. Come back tomorrow.The selection changes with the date. Videos can repeat; this isn't a no-repeat schedule.

The app runs entirely in your browser. Library updates are manual. Thumbnails and watch links connect to YouTube; imported files stay local.
